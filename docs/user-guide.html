3

了解四个接入阶段

根据项目的实际需求和当前状态，选择合适的接入阶段。每个阶段都有明确的定位。

0 最简单
超轻量接入包
⏱ 约 0.5 小时
无需游戏侧介入，平台开通权限即可用。适合新项目首轮验证期。
适合场景
快速上线、数据验证
1 推荐
基础接入包
⏱ 3–7 天
按文档开发，几乎无需定制。适合有数据基础的项目推广期或换皮项目。
适合场景
常规运营需求
2 进阶
升级接入包
⏱ 7–14 天
小部分需配合定制。适合稳定运营期、战略级项目。
适合场景
深度定制、大DAU游戏
3 深度
深度开发包
⏱ 7–14 天
纯定制，需深度协作联合评审。适合长期核心头部产品。
适合场景
头部产品、深度集成

8

常见问题

Q 可以中途更换接入阶段吗？ ▼
可以。进入项目详情页，点击右上角的「编辑项目」，可以重新选择接入阶段。选择更高阶段会自动补充新功能，选择更低阶段不会删除已选功能。
Q 项目暂停了怎么办？ ▼
在项目列表页，点击状态标签可以将项目标记为「暂停」。暂停的项目会自动移到列表底部，不影响数据。
Q 功能库中没有需要的功能怎么办？ ▼
在新建项目时，点击底部的「添加自定义功能」，填写功能名称和接入方式即可。自定义功能会在项目创建时自动添加到功能库中。
Q 接入流程步骤可以自定义吗？ ▼
可以。进入「管理后台」→「阶段规则配置」，可以查看和修改各阶段的功能配置和流程说明。
Q 如何管理功能库和文档？ ▼
进入「管理后台」，点击「功能库配置」可以管理所有功能，支持拖拽排序。点击「文档管理」可以管理接入文档、使用手册等资料。
